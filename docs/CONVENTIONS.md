# 코드 규칙 (초안)

이 저장소 코드를 고치거나 더할 때 지키는 규칙이에요. 사람과 AI 세션이 같이 봐요.

- **1부**: 지금 코드가 이미 지키고 있는 것.
- **2부**: 새로 정할 것(제안). 사용자가 정하면 1부로 옮겨요.
- **3부**: 그중 기계로 확인하는 것. `test/conventions.test.mjs` 가 지켜요.

이유는 하나예요. 코드가 깔끔해야 나중에 읽기 편해요. 파일이 작고 구역이 분명하고, 「왜」가 적혀 있으면 주말에 혼자 읽어도 따라갈 수 있어요.

2026-11-16 초안. 구조 · 보안 설명은 [코드 지도](ARCHITECTURE.md), 할 일은 [로드맵](ROADMAP.md)에 있어요.

## 1부. 지금 지키는 규칙

### 바탕

- **외부 패키지 0개, 빌드 없음.** Node 에 들어 있는 것만 써요(`node:fs` · `node:http` · `node:test` …). 화면도 `<script>` 로 그대로 불러요.
- **Node 18 이상.** 18 에 없는 것은 쓰지 않아요. 예: `import.meta.dirname` 대신 `fileURLToPath(new URL('..', import.meta.url))`.
- 답변 · 커밋 · 문서 · 주석 · 화면 문구 · 오류 문장은 **한국어**. 쉬운 말로 쓰고, 결과를 먼저 적어요.

### 파일과 이름

| 무엇 | 규칙 | 예 |
|---|---|---|
| 서버 쪽 파일 | `.mjs`, 소문자 낱말을 `-` 로 이음 | `lib/claude-settings.mjs` · `lib/open-dir.mjs` |
| 화면 파일 | `public/js/NN-이름.js`, 번호 순서대로 불러옴 | `04-list.js` · `17-live.js` |
| 화면 모양 | `public/css/NN-이름.css`, 번호 순서대로 불러옴(`<link>`) | `03-graph.css` · `12-narrow.css` |
| 테스트 | `test/<대상>.test.mjs`, 도우미는 `test/_helpers/` · `test/_*.mjs` | `test/paths.test.mjs` · `test/_history-full.mjs` |
| 함수 · 변수 | camelCase | `buildState` · `pruneUploads` |
| 고정값 | 대문자 + `_` | `SCAN_MS` · `ALLOWED_HOSTS` · `UPLOAD_MAX` |
| 상태를 가진 모듈 | `createXxx(deps)` 가 함수 묶음을 돌려줌 | `createCommands` · `createStateBuilder` · `createRunner` |

### 구역(모듈 경계)

```
server.mjs ──▶ lib/ · adapters/        (요청 입구 · 경로 표 · 2초 틱 · 구역 잇기)
adapters/  ──▶ lib/                    (도구별 기록 읽기. 서버를 모른다)
lib/       ──▶ lib/                    (구역별 일. 서버 · 어댑터를 모른다)
bin/       ──▶ lib/ · server.mjs       (실행 명령)
public/    ──▶ (서버 파일을 import 하지 않는다 — HTTP 로만)
```

- **보안 검사(Host · 출처 · 로그인 쿠키 · 요청 머리글)는 `server.mjs:handle` 한 곳**에서만 해요. 경로가 늘어도 검사를 빠뜨리지 않게요.
- 도구마다 다른 점은 **`adapters/` 에만** 둬요. 새 에이전트는 어댑터 파일 하나로 붙여요.
  - 어댑터가 커지면 그 도구만 아는 조각을 `adapters/<id>/` 폴더로 떼고, 입구(`adapters/<id>.mjs`)가 불러 써요. 서버 · lib 는 입구만 불러요(예: `adapters/claude/`). 여러 도구가 같이 쓸 일은 `lib/` 에 둬요(`lib/history-core.mjs` · `lib/git-commits.mjs`).
  - **예외 — Claude 전용 lib**(2026-11-18 정함): 새 세션 · 복구 · 승인 창 · 사용 한도는 지금 Claude Code 만 지원해서, 그 일은 lib 에 Claude 것으로 둬요. 새 도구가 같은 기능을 갖게 되면 그때 아래 자리로 옮겨요(미리 나누지 않아요).

    | lib 파일 | Claude 만 아는 것 | 새 도구가 생기면 옮길 자리 |
    |---|---|---|
    | `spawn.mjs` | `claude --session-id` · `--name` · `--model` 인자 | 어댑터 `newSessionArgs(o)` |
    | `restore.mjs` · `restore-cli.mjs` · `recent.mjs` | `claude --resume <ID>`, 복구 목록의 도구가 `claude` 하나 | 어댑터 `resumeCommand(e)` · 목록 항목에 `tool` |
    | `dialog.mjs` · `approval.mjs` | Claude Code 화면의 영어 안내 문구 · 선택지 모양 · 도구 이름 | 어댑터 `dialog(screen)` · `summarizeTool` |
    | `claude-settings.mjs` · `bridge.mjs` · `usage-bridge.mjs` | `~/.claude/settings.json` 상태줄 · 기본 모델 · 상태줄 값 | 어댑터 `usage` 조각 |
    | `env.mjs` | `claude --version` 등 환경 점검 줄 | 어댑터 `envItems()` |
    | `server.mjs` | `adapters/claude.mjs` 의 `unknownStatuses` 를 직접 부름 | 어댑터 목록에서 모으기 |

### createXxx(deps)

- 필요한 것만 객체로 받아요. 머리 주석의 `deps:` 목록을 보면 무엇에 기대는지 알 수 있어요(`lib/commands.mjs` · `lib/state.mjs` · `lib/env.mjs`).
- **바뀌는 값은 함수로** 받아요. 예: `hasState: () => Boolean(latest)`. 값을 그대로 넘기면 넘긴 순간의 값에 묶여요.
- 시간이 걸린 판단은 **시계를 넣을 수 있게** 해요. 예: `createNotifier({ now })` · `createLru({ now })` · `pruneUploads(dir, now)`. 테스트가 기다리지 않고 시간을 돌릴 수 있어요.

### 주석

- **파일 맨 위에 「무엇을 · 왜」를** 한두 줄로 적어요. 예: `lib/uploads.mjs` 는 「첨부 폴더와 정리. 스크린샷에 민감한 화면이 섞이기 쉬워 14일 지나면 지운다」.
- 몸통 주석은 **「왜」만** 적어요. 코드가 하는 일을 다시 말하지 않아요. 겪은 사고가 이유라면 그것도 짧게 적어요. 예: 「예전엔 폴더에서 rmSync 가 던져 정리가 멈췄다」.

### 서버 응답 · 오류

- 응답은 `lib/respond.mjs` 의 `sendText` · `sendJson` 으로 보내요. 오류는 **짧은 한국어 문장, `text/plain; charset=utf-8`** 이에요.
- 시스템 오류 원문(경로 · 영어 · `ENOENT`)은 로그에만 남기고, 화면에는 `friendly` 로 바꾼 문장을 보내요.
- 응답 코드의 뜻은 아래처럼 맞춰요.

| 코드 | 뜻 |
|---|---|
| 400 | 요청 값이 틀림 |
| 403 | 보안 검사(Host · 출처 · 로그인) |
| 404 | 없는 것 |
| 409 | 지금 상태에선 안 됨(승인 대기 중 · tmux 밖 · 다시 여는 중) |
| 413 | 너무 큼 |
| 503 | 아직 준비 중(첫 상태 전) |
| 500 | 예상 못 한 오류 |

### 파일 · 외부 명령

- `~/.agent-dashboard` 는 폴더 700 · 파일 600 이에요. 쓰기 전에 **링크면 거절**하고(`lstat`), 파일은 **`lib/atomic-write.mjs` 의 `writeAtomic`(난수 임시 파일 `wx` → rename)** 으로만 써요 — 그 자리에 링크가 있어도 따라가지 않아요(2026-11-17 점검 C7, 3부 검사: `writeFileSync` · `appendFileSync` 금지). `bin/statusline.mjs` 는 따로 실행되는 파일이라 같은 방식을 안에 둬요.
- 「폴더 안인가」는 `lib/paths.mjs:isInside` 하나로 봐요. `startsWith` 만으로는 옆 폴더(`uploads-x`)도 통과해요.
- **모듈은 import 만으로 프로세스를 끝내거나 밖에 쓰지 않아요.** `lib/` · `adapters/` 의 맨 바깥에서 `process.exit` · `console.*` · 파일 쓰기를 하지 않고, 그런 일은 함수로 내보내 부르는 쪽(`server.mjs` · `bin/`)이 불러요. 예: `lib/node-check.mjs:checkNode()` 를 bin · server.mjs 맨 앞에서 부름. 불러오기만 한 테스트가 끝나 버리거나, 읽는 사람이 「어디서 끝나는지」 찾기 어려워지지 않게요.
- 외부 명령은 **`execFile` · `spawn` 에 인자 배열**로 불러요. 셸을 거치지 않아요. 사람이 쓴 글은 stdin(`tmux load-buffer`)으로 넘겨요. 명령 인자는 `ps` 로 다른 계정에도 보여서 프롬프트 같은 글은 싣지 않아요(새 세션 첫 프롬프트도 입력칸이 뜬 뒤 붙여 넣기, 2026-11-17). 꼭 인자로 넘길 땐 `--` 뒤나 `--이름=값` 한 칸으로.
- 프로세스는 **내가 띄운 것만, 적어 둔 PID 로만** 꺼요(CLAUDE.md 「프로세스 끄기 사고」). 코드도 같아요: 실행기는 자기 자식에게만 신호를 보내고, 복구는 띄우기만 해요.

### 화면(public)

- **번호 순서로 불러오고, 뒤 파일이 앞 파일 것을 써요.** 모든 파일이 같은 전역을 함께 써요.
  - 여러 파일이 같이 쓰는 상태(`drawerTab` · `canSend` · `envData` …)와 도우미(`fmtTok` · `modelName` …)는 맨 앞 `01-core.js` 에 둬요.
  - 앞 파일이 뒤 파일 것을 쓰는 곳: let · const 는 0곳, 서로 부르는 function 8곳만 남았어요(ARCHITECTURE 8절 · 아래 2부 ④).
- 서버 요청은 **`01-core.js` 의 `apiFetch`(`api` · `apiJson`) 한 길**로만 해요. 403 이면 서버가 준 「로그인이 필요해요 — … open」 안내를 한 곳에서 띄워요. 요청마다 `X-Dashboard-Request: 1` 을 붙여요(CSRF).
  - 예외는 `17-live.js` 의 연결 확인(`/api/perf`) 하나예요.
- **인라인 스크립트 · `onclick=` 같은 속성 · `javascript:` 주소를 쓰지 않아요.** CSP(`script-src 'self'`)가 막아 단추가 조용히 죽어요. 동작은 js 파일에서 `addEventListener` 로 이어요(3부 테스트).
- 서버에서 온 글자를 HTML 에 넣을 땐 **언제나 `esc()`** 를 거쳐요. 속성(`class="…"`) 자리도 마찬가지예요.
- 다시 그릴 땐 `setHtml(el, html)` 을 써서 바뀐 곳만 바꿔요. 「N초 전」처럼 자주 바뀌는 글자는 따로 고쳐요(`updateAgo`).
- 브라우저 저장 키는 `agent-deck` 하나예요. 바꾸면 사용자 설정이 초기화돼요.
- **화면 파일(`public/`)에는 토큰이 없어요.** 화면은 로그인 없이 누구나 받을 수 있어서(같은 Mac 의 다른 계정 포함)요. 로그인은 `agent-dashboard open` 의 로그인 링크 → HttpOnly 쿠키(`lib/auth.mjs`)이고, 주소 · 머리글에 토큰을 싣지 않아요(2026-11-17, 사용자 승인).
- 모양(css)도 **그 단추 · 칸이 있는 구역 파일**에 둬요(머리 단추가 여는 팝업은 `01-header.css`, 프로젝트 박스의 폴더 메뉴는 `03-graph.css`).
- **`@media`(좁은 창 · 휴대폰 · 동작 줄이기)는 마지막 파일(`12-narrow.css`)에만** 둬요. 뒤 파일의 기본 규칙이 앞 파일의 `@media` 를 거꾸로 덮지 않게, 그리고 「좁은 화면에서 무엇이 빠지나」를 한곳에서 보게요(2026-11-17).

### 화면 디자인 규칙 (2026-11-18 리디자인)

오래 켜 두고 보는 화면이라 **한눈에 꼭 필요한 것만** 보이고, 나머지는 「더 볼 게 있는 곳」 표시 · ⓘ · ⋯ 메뉴 · 도움말로 보내요.

### 테스트

- `node --test` 와 `node:assert/strict` 만 써요. 테스트 이름은 한국어로 「무엇: 기대」 꼴로 써요. 예: `'isInside: 자기 자신 · 아래는 안, 옆 폴더 · 부모 · .. 로 빠져나간 것은 밖'`.
- **실제 홈 · 실제 tmux 에 닿지 않아요.**

### ② 나누는 기준

- **화면 기능은 그 단추 · 칸이 있는 화면 구역 파일에 둬요.** 예: 바꾼 파일 · 진행 표시는 지금 탭(`08-now.js`), 📎 첨부는 입력 칸(`09-attach.js`), 승인 카드 · 단추는 승인 창(`05-approval.js`). 2026-11-16 `07-changes.js` 를 나눈 근거예요.
- **파일 하나 = 하는 일 하나.** 머리 주석의 「무엇을」이 「·」 세 개를 넘거나, 서로 부르지 않는 함수 묶음이 둘 이상이면 나눌 때예요.
- 나눌 땐 **동작을 그대로** 두고, 원래 자리에 「어디로 옮겼는지」를 남기지 않아요. 지도(ARCHITECTURE 2절 표)를 고쳐요.
- 화면은 새 파일을 끝 번호 뒤에 붙이지 말고 **쓰는 쪽보다 앞 번호**에 둬요(번호를 다시 매겨도 돼요).

### ③ 이름

- 파일 이름은 **그 파일이 하는 일**로 지어요(`lib/uploads.mjs` = 첨부). `util` · `helpers` 처럼 무엇이든 들어갈 이름은 새로 만들지 않아요.
  - `lib/util.mjs` 는 「기록 파일 한 줄씩 · 끝 몇 줄 읽기」 도구라서, 이름을 바꿀지(예: `lib/jsonl.mjs`) 따로 제안해요. 2026-11-16 은 그대로 뒀어요(어댑터 · 테스트가 많이 불러요).
- 상태를 가진 모듈은 `createXxx(deps)` 를 쓰고, 머리 주석에 `deps:` 목록을 적어요. 상태가 없으면 함수를 그대로 내보내요.
- 화면 공용 도우미(`fmtTok` · `ctxLevel` · `modelName` · `initials` …)는 `01-core.js` 에 둬요.

### ④ 화면 번호 순서 (2026-11-16 사용자 결정)

- **뒤 → 앞이 기본이에요.** 뒤 번호 파일이 앞 번호 파일 것을 불러요.
- **let · const 는 예외 없음.** 앞 파일이 뒤 파일의 let · const 를 쓰면 안 돼요. 여러 파일이 같이 쓰는 상태 · 도우미는 `01-core.js` 에 둬요(선언한 줄이 실행되기 전에 쓰면 ReferenceError 라서).
- **서로 부르는 function 만 이유와 함께 허용**해요. 두 파일이 서로 불러서(고리) 번호를 어떻게 바꿔도 한쪽은 앞→뒤가 되는 경우예요.
  - `test/conventions.test.mjs` 의 허용 목록에 「되돌아오는 길」을 적어 두고, 목록은 줄어들기만 해요.
  - function 은 끌어올려져(hoisting) 불러오기가 끝난 뒤 부르면 안전해요. 불러오는 도중(파일 맨 위 코드)에는 뒤 파일 function 을 부르지 않아요.
- 고리가 아닌데 앞→뒤로 부르게 되면 번호를 바꿔요(2026-11-16: 조직도 03 · 목록 04, 환경 점검 09 · 한도 10 · 패널 11 · 다시 그리기 12).
- `index.html` 의 `<script>` 는 `public/js` 의 파일 전부를 번호 순서대로 불러요(3부 테스트).

### ⑤ 모듈 경계

1부 「구역」 그림을 규칙으로 정해요. 3부 테스트가 지켜요.

- `bin → lib · bin · server.mjs` 만.
- `server.mjs → lib · adapters` 만.
- 아무도 `public/` · `test/` 를 import 하지 않아요.

- 맨 위 「무엇을 · 왜」는 **모든 서버 · lib · 어댑터 · bin · 화면 js 파일**에 둬요(3부 테스트).
