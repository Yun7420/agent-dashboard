Checking environment…

    

      
Good to know

      
    
        
  • This computer only. It opens on 127.0.0.1 alone, and prompts and code paths are shown as they are, so don't share the address with anyone.
    • 
        
  • Chat · approve · end work only for sessions started in tmux. Sessions from a plain terminal or editor (Cursor etc.) are view-only. + New session opens one inside tmux for you.
    • 
        
  • Approve buttons grant real permissions. Check the terminal screen (command · file) in the panel before you press.
    • 
        
  • If a session's default permission mode is auto, most actions are allowed automatically and approval prompts rarely appear.
    • 
        
  • Structure tab: drag to move · wheel or the + − buttons to zoom · double-click to fit · click a node for its prompts. A blue arrow means messages between sessions.
    • 
        
  • Shortcuts: j/k next · previous session, g or Enter open panel, / search everything, in the message box Enter send · Shift+Enter new line, in an approval prompt 1~9 choose · Esc reject (if marked risky, press the same number again within 2 seconds), otherwise Esc closes the panel. They don't work while you are typing.
    • 
      

    

    

      
Security key ~/.agent-dashboard/token

      

      
    
        
  • What is it? A password just for this dashboard. It is never put in the page; only a browser that came in through a login link made from this key can read logs and send commands (message · approve · end · new session).
    • 
        
  • How do I log in? Open the link printed in the terminal at start (10 min) or run agent-dashboard open (in the repo: node bin/agent-dashboard.mjs open); that browser stays logged in for 30 days. For another browser or after 30 days, open it again.
    • 
        
  • Why is it needed? Any website, other accounts or programs on this Mac can send requests to the dashboard address. Without a login they can't push commands into your Claude sessions.
    • 
        
  • Where does it come from? It is made automatically on this computer the first time you start. It sits in ~/.agent-dashboard/token in your home folder, readable only by you (600), outside the repo and package folders, so it never ends up in git. Nothing to do.
    • 
        
  • Careful Don't send it to anyone. If it leaked, delete that file and restart the dashboard: you get a new key and every login is signed out (open again with a login link).
