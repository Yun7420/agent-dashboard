  • 무엇인가요? 이 대시보드 전용 비밀번호예요. 세션에 메시지 보내기·승인·종료·새 세션 같은 명령은 이 열쇠를 가진 이 화면에서만 받아요.
    • 
        
  • 왜 필요한가요? 브라우저에서는 아무 웹사이트나 내 컴퓨터의 대시보드 주소로 요청을 보낼 수 있어요. 열쇠가 없으면 악성 사이트가 몰래 내 Claude 세션에 명령을 넣을 수 있어서, 열쇠가 맞는 요청만 통과시켜요.
    • 
        
  • 어떻게 생기나요? 처음 켤 때 이 컴퓨터에서 자동으로 만들어져요. 사람마다 다른 열쇠가 생기고, 할 일은 없어요.
    • 
        
  • 주의할 점 다른 사람에게 보내거나 깃에 올리지 마세요(자동으로 제외돼 있어요). 혹시 새어 나갔다면 파일을 지우고 대시보드를 다시 켜면 새 열쇠로 바뀌어요.
